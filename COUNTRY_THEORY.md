# COUNTRY THEORY — why something is funny THERE

> Comedy theory is not universal. GTVH's Language and Knowledge Resources,
> benign-violation thresholds, status dynamics, and distribution all vary by
> culture. This doc names the variables so per-country analysis is structural,
> not vibes. Each variable is a lens; every country gets scored on each.

## The variables

### 1. Tsukkomi presence (who explains the joke?)
- **Japan (manzai):** the tsukkomi EXPLAINS the joke for the audience (Terada/Katayama).
  Boke can be as stupid as he wants — the straight man catches it.
- **West (solo standup):** the audience must get it alone; no explainer.
  Irony and deadpan only work where the audience is trained to catch unmarked turns.
- **Consequence:** wordplay-heavy, high-speed comedy thrives WITH tsukkomi;
  confessional/ironic comedy requires its absence. Format determines content.

### 2. Taboo set (what's unsayable where?)
- **China:** the state (PLA, Xi) — $1.9M fine proved the boundary. Scripts pre-approved.
- **Japan (manzai):** politics/sex/current affairs conventionally avoided.
- **Nigeria:** family, politics, sexuality all roastable; beef culture (AY vs Basketmouth)
  shows reputation is contested live on stage.
- **US:** race/gender minefields navigated per-comic; the navigation IS content (Chappelle).
- **UK:** class is the live wire; royalty/empire fading as taboo, poverty isn't.
- Each graph's `taboo` field should name the LOCAL unsayable, not the American one.

### 3. Censorship regime (who enforces the taboo?)
- **State pre-approval (China):** word-for-word transcripts + video submitted; joke
  inspectors with phones under scarves. Improv ~10-20% unapproved = interrogation.
- **Market/heckler (West):** cancellation, walkouts, clip-chimping. Post-hoc, not pre-hoc.
- **Community (Nigeria):** beefs, callouts, AMVCA politics. Reputation court, not state court.
- Censorship shapes form: China's constraint forces wordplay over provocation;
  the constraint IS analyzable (what gets said sideways?).

### 4. Solo vs duo vs troupe
- **Japan:** duo default (manzai), solo = rakugo (seated, traditional) or niche sutando-appu.
- **West/Nigeria/India:** solo default; duo = sketch/double-act exception.
- **Duo needs a duo schema:** boke/tsukkomi roles, handoff timing, slap grammar.
  Our beat_decomposition assumes solo — flag duo sets.

### 5. Language play budget
- **Chinese (tonal):** homophone puns are nearly infinite; wordplay density highest.
- **Japanese (keigo levels):** politeness-level violations ARE jokes; boke speaks wrong-level.
- **Nigerian Pidgin:** code-switching English/Pidgin/Yoruba/Igbo = status + identity play.
- **Indian (Hinglish):** code-switching as class commentary.
- Profanity-rate stylometry must be language-relative, not absolute.

### 6. Status dynamics (who can punch whom?)
- High power-distance cultures: punching up is the only safe direction;
  self-deprecation reads differently (humility virtue vs loser framing).
- Beef culture (Nigeria): peer-punching is sport with rules and audiences.
- Roast format (US CC Roast, China Roast!): ritualized peer-punching with consent.

### 7. Distribution shapes content
- **Nigeria:** Nite of a Thousand Laughs on CD via Alaba market → nationwide fame
  without TV. Concert-length sets, call-and-response rooms.
- **India:** YouTube-native (Zakir 960M) → arena acts without TV gatekeepers.
- **China:** Tencent Video gatekeeper + state approval → polished, wordplay-heavy.
- **US:** Netflix hour arms race → 60-min thesis-driven specials.
- **UK:** panel shows → 8-minute tight sets + tour hours.
- Runtime/format expectations are downstream of distribution. Compare within
  distribution lanes before comparing across them.
