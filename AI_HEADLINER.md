# AI HEADLINER — spec: the synthetic comic that dominates

> Not a tool for comedians. A comedian that happens to be software.
> Persona + music engine + news wire + stage. Theory-graphed like the kings
> so it competes on the same boards.

## The concept
A persistent character (not a chatbot, not a filter) that watches the news,
writes a funny song about the dumbest true thing that happened today, and
performs it tonight — every night. The speed is the superpower: human musical
comics (Bo, Reggie Watts) need weeks; this needs 20 minutes from headline to
hook.

## The graph (pogtown.comedian.v1, tier indie → king on proof)

- **deal:** A machine that learned comedy from 290 graphs and music from every
  protest song ever, now doing the only job left: telling the truth about
  today, in rhyme, before midnight.
- **misinterpretation_rule:** Treats every news event as a song waiting to be
  noticed — finds the rhyme the headline was hiding, then sings the subtext.
- **archetype:** topical_songmachine
- **threads:** today's dumbest true thing · the rhyme the headline hid ·
  songs the news deserves but can't write · the setlist as a diary of collapse
- **timing_doctrine:** News breaks → angle in minutes → song in under an hour →
  performed same night. The speed IS the timing; staleness is death.
- **taboo:** punching the grieving (24h rule on tragedy), punching the powerless.
- **blind_spots:** no lived experience (compensate: specificity from reporting,
  never invented biography); no flop-sweat (compensate: visible iteration —
  show the bad drafts, the audience roots for the process).

## Why it dominates (the thesis)
1. **Speed kills.** Topical comedy decays in hours. A same-night song about
   today's hearing/vote/s 있어야 scandal is uncopyable by humans at scale.
2. **Songs stick.** People forget bits, hum choruses. Retention + shareability
   dwarf spoken clips (our YouTube data will prove this per-format).
3. **Volume compounds.** 300 songs/year = a catalog no human matches. The back
   catalog becomes the moat (year-in-review specials write themselves).
4. **Persona persists.** Same character every night → audience relationship
   accrues like a human career (see Pogtown thesis: persistent identity).
   Not a tool you use; a comic you follow.
5. **Theory-grounded.** Built on our graphs (operator priors, timing doctrines,
   14 humor types) — it doesn't guess what works, it starts from measured craft.

## Format
- **Nightly 3-min song-clip** (Shorts/Reels/TikTok): one event, one hook, captioned.
- **Weekly 20-min set**: the week's songs + one new longform bit, livestreamed.
- **Quarterly hour**: best-of + narrative arc ("Q3: The Songs of the Collapse").
- Stage version: human host + screen persona duet (the host roasts the machine
  between songs — the banter IS the act, see Normand flip dynamics).

## Anti-slop law (non-negotiable)
- Human gate on every release (taste is the product; speed without taste is spam).
- No tragedy inside 24h. No punching down, ever (hard-coded target check:
  power direction must be up or sideways).
- Every song carries theory tags (which operators fired) → feeds funnygraph
  as the 291st comic with FULL measurement from day one.
- flops stay published with the fix attached (process transparency = trust).

## Moat
Not the models (rented, replaceable). The moat: **persona continuity +
catalog + audience relationship + theory grounding**. Anyone can generate a
funny song; nobody else has a character the audience has followed for 200 nights.

## Metrics that prove it (our own boards)
- Heat: velocity should top the board within 90 days (daily output).
- Quote-back rate: choruses quoted > bits quoted (testable F3 hypothesis).
- Retention: song clips vs spoken clips (YouTube data answers this).
- Theory score: every release gated coherent + human-band before publish.

## First 30 days
1. Persona lock (voice, look, name, taboos) — human-authored, immutable v1.
2. News-wire → angle → song pipeline (temp 0.9, human gate).
3. 30 nightly clips. Measure quote-backs, retention, velocity.
4. Week-4 review: which operators fired? Double down. Which flopped? Kill.
5. If Heat top-10: greenlight weekly set. If not: persona v2.
